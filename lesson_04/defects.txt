ID: BUG-001
Заголовок: Метод contains не обрабатывает None и вызывает AttributeError вместо TypeError
Компонент: string_utils.py, метод contains
Приоритет: Medium
Серьезность: High

Шаги воспроизведения:
1. Создать экземпляр класса StringUtils.
2. Вызвать метод contains(None, "a").

Ожидаемый результат:
Метод должен корректно обрабатывать некорректный ввод и выбрасывать исключение TypeError (как ожидается в тесте test_contains_none).

Фактический результат:
Возникает исключение AttributeError: 'NoneType' object has no attribute 'index'.

Дополнительная информация:
В реализации метода используется вызов string.index(symbol), который неприменим к объекту None. Отсутствует проверка входных данных на None.
